## Curation Note

Predates HDB's Oct 2024 Standard/Plus/Prime classification framework AND predates the 2-Room Flexi scheme. Single standalone project, all 4-Room. Second phase of the Coralinus development — Coralinus 1 (Jun 2005, 369 units per housingmap.sg) is not yet in this dataset; uses project key 'CORALINUS (PHASE 2)' to stay distinct once Phase 1 is added, same convention as Jade Spring's and Fernvale Vista's phases. This is the **most data-poor launch found in this entire backfill**: the VSF microsite's price table was itself a JPEG image (06FEBBTOPG_img_price.jpg) rather than an HTML table, and that image was never actually captured by Wayback despite the containing HTML page being archived (a new failure mode, distinct from every other gap found so far in this backfill — confirmed via CDX search returning zero results for the image URL at any timestamp). No steps/application-date page was successfully crawled either (both attempted URLs 404). No secondary news source, forum thread, or press release covering this specific launch could be found (one promising forum thread title, 'HDB's latest Build-to-Order project, CORALINUS is back with 6 brand new blocks,' from punggol.sg, is itself now a dead 404 with no Wayback capture). Unit type (all 4-Room) and total (365, matching housingmap.sg) are inferred from the current merged live listing for the combined Coralinus site (which describes all 734 combined units across both phases as '4 room flat types', and 369 [Phase 1] + 365 [this launch] = 734 reconciles exactly) — but no price, floor area, or exact application dates could be recovered from any source. application_start recorded as 2006-02-01 (first of the housingmap-designated month) purely so status computes 'closed'; this is the least-confident date approximation in the entire backfill, with no anchor point (no confirmed close date to work backward from, unlike every other approximated date in this dataset).
