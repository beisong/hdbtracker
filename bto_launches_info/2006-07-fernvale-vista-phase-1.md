## Curation Note

Predates HDB's Oct 2024 Standard/Plus/Prime classification framework AND predates the 2-Room Flexi scheme. Single standalone project, Standard Apartments (contract Sengkang N4 C7). Earlier phase of the same physical Fernvale Vista development whose Phase 2 (May 2007, 678 units) is already in this dataset as launch_id 2007-05, project 'FERNVALE VISTA (PHASE 2)' — uses 'FERNVALE VISTA (PHASE 1)' here to stay distinct. This project's legacy VSF microsite has no price page ever crawled by Wayback (only steps/about frame pages) — exact per-type unit counts and prices were instead recovered from a contemporaneous wedding-forum thread actively tracking the launch in real time (86x2-Room $54,000-$75,000, 92x3-Room $94,000-$123,000, 330x4-Room $131,000-$182,000, reconciling exactly to 508 units, matching housingmap.sg's total exactly). Application period (24 Jul - 14 Aug 2006) confirmed both from this forum thread AND independently from the VSF's own steps page ('Apply by 14th August 2006') — the two sources agree exactly, and this is a rare pre-2008 launch with a fully-confirmed (not approximated) application_start. Cross-validation: current live listings for the combined Fernvale Vista development (both phases now merged into one physical site) report 1,186 total units, exactly matching 508 (this launch) + 678 (Phase 2) = 1,186. Floor area not published in any source found — recorded null.
