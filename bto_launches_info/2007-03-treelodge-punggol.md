# Treelodge @ Punggol

**Launch:** March 2007 BTO (2007-03-28 to 2007-04-17)
**Town:** PUNGGOL (Non-Mature Town)
**Location:** Junction of Punggol Road, Punggol Drive and Punggol Place. Singapore's first eco-precinct public housing development, first Green Mark Platinum Award public housing project. Premium flats.

## Curation Note

Predates HDB's Oct 2024 Standard/Plus/Prime classification framework AND predates the 2-Room Flexi scheme. Single standalone project, Premium flats (contract PGW S3 C7). Treelodge @ Punggol is a notable landmark project — Singapore's first eco-precinct public housing development and first Green Mark Platinum Award public housing project. Project name is 'TREELODGE@PUNGGOL' with no spaces in OneMap's own SEARCHVAL field, but renamed to 'TREELODGE @ PUNGGOL' (spaces around @) per this dataset's established naming convention (documented bug caught earlier in this backfill for TREETRAIL@WOODLANDS). Recovered from HDB's legacy VSF microsite (www.hdb.gov.sg/hdbvsf/eampu03p.nsf/..., a plain www subdomain rather than www69/www101 as seen for other 2007 launches, captured in Wayback) as plain-text HTML: exact official table gives 98x3-Room (65 sqm internal, $139,000-$165,000), 600x4-Room (90-93 sqm internal, $208,000-$254,000), 14x5-Room Loft (111 sqm internal, $370,000-$383,000), reconciling exactly to 712 units, matching housingmap.sg's total exactly. Application close date (17 Apr 2007) confirmed from the VSF's own steps page; launch date (28 Mar 2007) independently confirmed via multiple secondary sources describing this specific project's well-documented launch history (it is Singapore's first eco-precinct, more widely written about than most other launches from this era) — higher confidence than the pure-inference approximations used for Aug/Nov 2007's less-documented launches.
