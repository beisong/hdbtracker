# Straits Vista @ Marsiling

**Town:** WOODLANDS (Non-Mature Town)
**Location:** Marsiling Lane, Woodlands.

## Curation Note

Predates HDB's Oct 2024 Standard/Plus/Prime classification framework AND predates the 2-Room Flexi scheme. Single standalone project, Standard flats (contract Woodlands N2 C12). A separate, earlier BTO exercise from the 30 Jun-14 Jul 2008 Punggol Breeze/Fernvale Residence launch (2008-06b) despite both falling in June 2008 — confirmed distinct application windows (this one: 10-23 Jun 2008, launch date corroborated by secondary blog coverage dated the same day) and the two projects were tracked separately in HDB's own legacy VSF site structure. Recovered from HDB's legacy 'virtual showflat' microsite (www101.hdb.gov.sg/hdbvsf/eampu06p.nsf/..., captured in Wayback) as plain-text HTML: exact official price table gives 50x3-Room (65 sqm internal, $116,000-$164,000), 332x4-Room (90 sqm internal, $184,000-$257,000), reconciling exactly to the 382-unit combined headline.
