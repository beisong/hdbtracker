## Curation Note

Predates HDB's Oct 2024 Standard/Plus/Prime classification framework AND predates the 2-Room Flexi scheme. Single standalone project, Standard flats + elderly Studio Apartments. Recovered not from a PDF brochure but from HDB's legacy 'virtual showflat' microsite (www101.hdb.gov.sg/hdbvsf/eampu02p.nsf/..., captured in Wayback) — a plain-text HTML price table, not rasterized, giving exact official figures directly: 60x Studio Apartment (35 sqm internal, $57,000-$64,000, for age 55+), 164x Studio Apartment (45 sqm internal, $71,000-$80,000, for age 55+), 182x3-Room (65 sqm internal, $118,000-$142,000), 224x4-Room (90 sqm internal, $194,000-$227,000), 185x5-Room (110 sqm internal, $247,000-$296,000) — reconciling exactly to the 815-unit combined headline. Application close date (11 Mar 2009) confirmed directly from the site's own steps/about pages. Studio Apartment units have no resale-market equivalent flat type (elderly-only, not typically resold as a distinct category in the resale dataset) so resale_flat_type is null for those two rows, consistent with the Studio Apartment convention used elsewhere in this dataset (e.g. Treegrove @ Woodlands, Feb 2010).
