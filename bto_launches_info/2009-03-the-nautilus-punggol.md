# The Nautilus @ Punggol

**Launch:** March 2009 BTO (2009-03-26 to 2009-04-08)
**Town:** PUNGGOL (Non-Mature Town)
**Location:** Junction of Punggol East and Punggol Field, near Coral Edge and Riviera LRT stations. 8 residential blocks, 16-18 storeys, Standard flats.

## Curation Note

Predates HDB's Oct 2024 Standard/Plus/Prime classification framework AND predates the 2-Room Flexi scheme. Single standalone project, Standard flats. Major new source discovered this session: HDB's own legacy brochure host (www100.hdb.gov.sg, directory pattern <yy><mon>BTO<town-code>_pdf/) is itself captured in the Wayback Machine back to at least 2008 — a more complete and authoritative brochure archive than housingmap.sg for this era, which only linked brochures from Dec 2009 onward. Full 'General Info' brochure recovered directly (image-based, read via page screenshots), giving an exact official Indicative Price Range table: 413x4-Room (92-93 sqm / 90 sqm internal, $228,000-$274,000) and 106x5-Room (112-113 sqm / 110 sqm internal, $305,000-$357,000), reconciling exactly to the 519-unit combined headline. Application close date (8 Apr 2009) confirmed directly from the brochure's own 'Simple steps to apply' page.
