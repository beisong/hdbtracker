## Curation note

**Gap-fill**: caught during the same systematic housingmap.sg completeness re-check as 2010-03/2010-04. Three projects launched together (2,696 units combined: 1072+504+1120), 30 Jun 2010, in Punggol (Waterway Terraces, the original/first Waterway Terraces exercise — disambiguated here as 'WATERWAY TERRACES I' since 'WATERWAY TERRACES II' already exists in this dataset at 2011-04) and Sengkang (Fernvale Foliage, Rivervale Arc). As with 2010-04, none of the three General_Info.pdf brochures contain a price table; unit counts were sourced from each project's Maps&Plans.pdf block-level unit-distribution table instead, all three reconciling exactly to housingmap.sg's totals (Waterway Terraces I: 178x3-Room + 588x4-Room + 306x5-Room = 1072; Fernvale Foliage: 336x4-Room + 168x5-Room = 504; Rivervale Arc: 238x2-Room + 221x3-Room + 661x4-Room = 1120). Prices (min and, where recoverable, max) are from aggregated secondary sources (not an official HDB price table): Waterway Terraces I (Premium flats) 3-Room $186,000-$237,000, 4-Room $300,000-$376,000, 5-Room $374,000-$458,000; Fernvale Foliage 4-Room $215,000-$280,000, 5-Room $279,000-$346,000; Rivervale Arc 2-Room from $68,000, 3-Room from $122,000, 4-Room from $201,000 (max not recoverable in the time available — recorded as price_max: null, per this dataset's existing min-only convention). Application close date could not be precisely sourced beyond 'closed in July 2010' per a secondary source (13,688 applications received for Waterway Terraces I alone); application_end left null rather than guessed, consistent with this dataset's documented convention for approximate/incomplete dates. Floor areas were not sourced for this launch (time-boxed); floor_area_sqm left null throughout, consistent with existing convention.
