## Curation note

Corporation Tiara is a special case like Sembawang RiverLodge (2010-03): its own table footnote states verbatim '190 units of Studio Apartments are reserved for future sale' — i.e. NOT part of this July 2010 exercise — so only the 275 actually-offered units (171x4-Room + 104x5-Room) are recorded here, not housingmap.sg's full 465 (which includes the 190 withheld Studio units); independently corroborated by a secondary source explicitly stating '275 units of 4-room and 5-room Premium flats were offered for sale' in this exercise, an exact match. Senja Gateway has no such reservation note — recorded at its full table total of 741 (124 Studio Type A + 130 Studio Type B + 313 4-Room + 174 5-Room).
