# Tampines Alcoves & Tampines GreenTerrace

**Launch:** January 2012 BTO (2012-01-11 to 2012-01-17)
**Town:** TAMPINES (Mature Estate)
**Location:** Tampines Avenue 9 / Tampines Avenue 1. Two separately-named HDB developments — Tampines Alcoves' Studio Apartment rows and Tampines GreenTerrace's 4-Room row are each project-exclusive, but the 3-Room row is explicitly shared across both in HDB's official Table A1 — combined into one entry accordingly.

## Curation Note

Predates HDB's Oct 2024 Standard/Plus/Prime classification framework AND predates the 2-Room Flexi scheme. **Official Annex A recovered in full** — the real HDB press-release PDF ('ANNEX A: INFORMATION ON JANUARY 2012 BUILD-TO-ORDER FLATS'), archived by kendata12345.wordpress.com as a genuine PDF (not just a rasterized cost-analysis image like other nearby launches), giving exact per-project data with zero reconstruction needed. Reconciles exactly to the press release's own 3,923-unit BTO headline (this was the first BTO launch of 2012). Tampines Alcoves & Tampines GreenTerrace combined per HDB's own official table structure: Tampines Alcoves' Studio Apartment rows and Tampines GreenTerrace's 4-Room row are each project-exclusive, but the 3-Room row (202 units, 67-69 sqm) is explicitly shared across both projects in Table A1 — kept as one combined entry accordingly. Fernvale Lea, Sunshine Gardens, and Waterway Sunbeam are all standalone.
