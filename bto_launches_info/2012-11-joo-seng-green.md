# Joo Seng Green

**Launch:** November 2012 BTO (2012-11-21 to 2012-11-27)
**Town:** TOA PAYOH (Mature Estate)
**Location:** Upper Aljunied Road / Joo Seng Road. Named after the neighbouring HDB blocks and NC. No 2-Room or 5-Room flats in this project.

## Curation Note

Predates HDB's Oct 2024 Standard/Plus/Prime classification framework AND predates the 2-Room Flexi scheme. Official Annex A (the real press-release PDF, not a secondary reconstruction) recovered via Wayback Machine CDX broad search on the old hdb.gov.sg Lotus Notes-style domain (www.hdb.gov.sg/fi10/fi10297p.nsf/ImageView/...) — archived as bto_launches_info/2012-11-annex-a-flat-supply.pdf. Reconciles exactly to the press release's own 6,463-unit BTO headline (2 non-mature towns: Choa Chu Kang, Sengkang; 3 mature towns: Bedok, Queenstown, Toa Payoh). Largest BTO supply in a year since the BTO system was introduced in 2002 (27,084 units for all of 2012). All 7 projects are fully standalone with independently-published per-project unit breakdowns — no combined entries needed at all (a plain web search of a secondary singpromos.com source had grouped some projects under shared page headers, e.g. 'Rivervale Delta & Compassvale Mast' and 'Joo Seng Green and Toa Payoh Crest', which looked like the partial-combine pattern seen elsewhere in this backfill, but the official Annex A confirms each project has its own complete, independent flat-supply table). Joo Seng Green is explicitly grouped under Toa Payoh Town by HDB's own press release text ('The other BTO project in Toa Payoh Town is Toa Payoh Crest'), despite being geographically closer to Potong Pasir/Woodleigh. Compassvale Mast is a Premium Flats project (higher-spec finishes, higher OCS optional-component costs) — no separate classification field exists for this distinction, only town Mature/Non-Mature. Fengshan GreenVille, Ghim Moh Edge, and Toa Payoh Crest each have two Studio Apartment size variants, kept as separate flat rows.
