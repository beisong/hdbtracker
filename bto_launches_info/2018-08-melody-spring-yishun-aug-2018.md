# Melody Spring @ Yishun (Aug 2018)

- **Launch**: August 2018 BTO (`2018-08`)
- **Town**: YISHUN
- **Classification**: Non-Mature Town
- **Location**: Bounded by Yishun Avenue 8 and Yishun Street 42, includes an Elderly Facility. No 3-Room flats in this project. HDB reused this project name for an unrelated later BTO launch at the same site in Nov 2018 — disambiguated by launch month/year.
