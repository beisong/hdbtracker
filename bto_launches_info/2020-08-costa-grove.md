## Curation note

Excludes 200 rental flats (58x 1-Room + 142x 2-Room, not for sale to the public) — the brochure's unit-mix table lists these alongside the 1,070 home-ownership (BTO-for-sale) units; flats[] contains only the home-ownership units. The 3-Room, 4-Room and 5-Room rows each span two floor-plan variants (a smaller standard unit and a larger balcony unit) sharing one unit count/price range in the source data — the smaller/standard sqm (69/93/113) is stored.
