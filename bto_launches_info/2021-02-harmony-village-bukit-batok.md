## Curation note

This project consists entirely of 169 Community Care Apartment (CCA) units (34 sqm, 30-year lease, seniors 65+ only, $52,000-$60,000 indicative) — CCAs are not standard BTO flats, so flats[] is empty here (same exclusion rule as CCA rows within otherwise-mixed projects elsewhere in this dataset). This launch's headline total of 3,740 flats includes these 169 CCA units; the sum of this launch's other projects' flats[] units is 3,571.
