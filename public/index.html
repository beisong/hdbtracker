Check HDB Resale Prices & Property Transaction History in Singapore

WorthIt is a free Singapore property tool that helps you check HDB resale prices, condo transaction records, and fair market value for any Housing & Development Board flat or private property. Search by town name, postal code, or project name to instantly view 370,000+ resale transactions from data.gov.sg and URA records.

How It Works

  • Search any HDB town (Bedok, Tampines, Jurong, Bishan, etc.), postal code, or private condo project name
  • View median resale prices, price trends over 5 years, price distributions, and percentiles (10th to 90th)
  • Compare Deal Scores — color-coded markers showing whether each transaction is good value or premium-priced
  • Explore an interactive map of recent transactions with MRT station overlays
  • Analyze private property (condo, apartment) resale data by district with URA transaction records

Covered HDB Towns

Ang Mo Kio, Bedok, Bishan, Bukit Batok, Bukit Merah, Bukit Panjang, Bukit Timah, Central Area, Choa Chu Kang, Clementi, Geylang, Hougang, Jurong East, Jurong West, Kallang/Whampoa, Marine Parade, Pasir Ris, Punggol, Queenstown, Sembawang, Sengkang, Serangoon, Tampines, Toa Payoh, Woodlands, Yishun — plus private properties across all 28 Singapore districts (D01–D28).

Data Sources

Transaction data from Housing & Development Board (HDB) via data.gov.sg and Urban Redevelopment Authority (URA) private property records. Postal code geocoding by OneMap Singapore. Updated monthly with the latest resale transaction records.
